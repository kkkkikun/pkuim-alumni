## 二、域名选型

| 项 | 建议 | 说明 |
|---|---|---|
| 后缀 | **`.cn`** 或 `.com` | `.cn` 便宜（首年几十元）、审核快；`.com` 通用性好、显得正式 |
| 注册商 | **阿里云（万网）** | 理由：备案接入商用阿里云，**服务器就在阿里云**（乌兰察布 `cn-wulanchabu`），备案「网站/APP 接入」一步到位；腾讯云也能做，但要换接入商、更麻烦 |
| 主体类型 | **企业**（校友会 / 运营公司）或**个体工商户** | ⚠️ **个人主体备案不能用于经营性业务**，小程序对外提供服务通常要求企业/个体主体；且小程序本身也要有对应的主体资质 |
| 保护性注册 | 建议同时注册 `.com` + `.cn` + 微信保护域名 | 防止被人抢注 |
| 不要用 | 免费动态域名（如服务器上现有的 `*.dpdns.org`） | 那是**别人域名的子域**，无法做 ICP 备案，也就不能用作小程序合法域名 |

## 四、备案通过后我要做的事（你不用管）

1. **DNS 解析**：加一条 A 记录 `api.<你的域名>` → `8.160.116.34`（需要你把域名 DNS 托管在阿里云，或给我 NS）。
2. **HTTPS 证书**：
   - 方案 A（推荐）：用服务器上**已有的共享 Caddy**（`openfeedback` 那个）加一个 vhost，
     Caddy 自动签 Let's Encrypt 证书并自动续期 → 走标准 **443**；
   - 方案 B：不动共享 Caddy，我在自己的边缘容器里签证书，用**非标准端口**（如 8443）。
     微信官方文档明确允许带端口的合法域名（`https://myserver.com:8080`），
     但配置后**请求 URL 必须与之一模一样**（不能省端口、也不能多写 `:443`）。
   - 我倾向 **方案 A**：443 是标准端口，兼容性最好；而且这台机器上已经有 Caddy v2 + 成熟的多 vhost 挂载脚本（`/opt/attach-caddy.sh`），复用它比新起一套更省事。
3. **小程序后台配置**（需要**管理员微信扫码授权**）：
   「开发管理 → 开发设置 → 服务器域名 → 修改 → request 合法域名」填 `https://api.<你的域名>`
   （`uploadFile` 合法域名同一栏再填一次，因为我们也上传认证材料）。
   ⚠️ **一个月只能改 5 次**，改之前想清楚。
4. **重新上传体验版**：构建期把 API 基址注入成 `https://api.<你的域名>/api/v1`，
   走一遍「产物对账」再上传；这次客户在**正常模式**下就能用，不需要开调试。

## 六、附：微信官方规则原文要点（`developers.weixin.qq.com`）

> - 域名只支持 `https`（`wx.request` / `wx.uploadFile` / `wx.downloadFile`）和 `wss`（`wx.connectSocket`）协议；
> - 域名不能使用 IP 地址（小程序的局域网 IP 除外）或 localhost；
> - 对于 `https` 域名，**可以配置端口**，如 `https://myserver.com:8080`，
>   但配置后只能向 `https://myserver.com:8080` 发起请求；
>   如果不配置端口（如 `https://myserver.com`），请求 URL 中**也不能包含端口**，甚至默认的 443 端口也不可以；
> - 域名必须经过 **ICP 备案**，**新备案域名需 24 小时后才可配置**；
> - 每类服务器域名最多支持配置 200 个；**不支持配置父域名，使用子域名**；
> - 配置服务器域名**需管理员扫码授权确认**。
